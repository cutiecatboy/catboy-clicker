# Catboy Clicker

A cozy little idle game: give Kaito a pat, collect fish snacks, and spend them
on click-power and passive-income upgrades. Progress saves automatically in the
current browser.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm test
npm run lint
npm run build
```
